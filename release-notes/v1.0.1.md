## CP/M Disk Wrangler 1.0.1

A bug-fix release.

### Microbee
- **New DS40 discs now work.** Choosing `microbee40` in File > New disc image made a disc of one side and 80
  cylinders (the same as SS80), not the 40 cylinders on two sides that a Microbee 5.25-inch DS40 disc has. Files could
  be written to it, but it wouldn't run on a DS40 drive. There is now a built-in `microbee-ds40` format (40 cylinders
  x 2 sides, 10 x 512, 2K blocks, 128 directory entries, 2 reserved tracks) which makes the right disc, with the side
  numbers 0 and 1 in the sector headers. Checked against a real DS40 disc, which it detects with high confidence.
- A new DS40 should be made as ImageDisk or DSK. A raw file of one has exactly the same bytes as an SS80, so opening a
  raw DS40 may name it SS80; the files read and edit the same either way.
- `microbee40` (cpmtools' name) is still in the list, now described as one side of 80 cylinders.

### Known limits
- As in 1.0.0: TeleDisk images can't be saved as TeleDisk (and TeleDisk 1.x "advanced compression" isn't supported); new
  Sharp `sds400` discs can't be made yet; deleted Torch CP/N files can't be recovered; the builds are not signed.
