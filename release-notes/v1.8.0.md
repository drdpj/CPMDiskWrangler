## CP/M Disk Wrangler 1.8.0

Single-density discs made right, double-sided Research Machines single-density discs, and a manual page for `cpmdw`.
It moves to the DiskWranglerCore library version 1.5.0 (from 1.4.2).

### New
- **Double-sided Research Machines single-density discs.** File > New disc image's "Double-sided: a separate disc on
  each side" box now works for `rm-sd` too, as it did for `rm-dd` and `rm-qd` (`cpmdw new --format=rm-sd
  --separate-sides`). A raw image of one (all of side 0, then all of side 1) opens as a disc on each side.
  (Issue #6.)
- **A manual page for `cpmdw`.** The Linux `.deb` installs it, so `man cpmdw` describes every command and option,
  with examples. `cpmdw COMMAND --help` now lists that command's options.

### Fixed
- **New single-density discs made as ImageDisk are FM.** They were written with MFM modes, so an emulator or disc
  writer that takes the density from the file got it wrong. This was so for IBM 3740 (8-inch), Zenith Z-100 SSSD
  8-inch and Intel MDS single density (FM 500 kbps), and for Research Machines single density, TRS-80 Omikron and
  Osborne 1 single density (FM 250 kbps). Saving a raw image of one as ImageDisk now gives FM too. These six formats
  are now among the program's own definitions ("built-in") instead of cpmtools'; their layouts are unchanged.
  (Issue #5.)

### Known limits
- While its second side is still empty, a raw double-sided `rm-sd` image is also an 80-track single-sided disc, so it
  opens read-only until its format is confirmed (an ImageDisk or DSK file of it opens writable).
- As in 1.7.1: TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported; a
  padded single-sided 80-track Research Machines disc (`rm-qd`) is the size of a padded double-sided 40-track one and
  opens read-only until its format is confirmed; copy-protected tracks are read but never written; DateStamper time
  stamps are kept but not shown; deleted Torch CP/N files can't be recovered yet; the builds are not signed.

### Building from source
The shared code is the DiskWranglerCore library (version 1.5.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release. For 32-bit
Windows (Windows 7 SP1 and later), see `core/docs/building-windows-32bit.md`.
