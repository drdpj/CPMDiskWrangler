## CP/M Disk Wrangler 1.7.1

A maintenance release: it moves to the DiskWranglerCore library version 1.4.1 (from 1.3.0). Nothing changes in how
the program reads or writes discs.

### Changed
- The documents are brought up to date: the README's drag-and-drop and building sections now cover all three Disk
  Wranglers (Acorn, CP/M and FLEX), and the shared library's guides name FLEX Disk Wrangler and its console program.
- Files dragged from Acorn Disk Wrangler's tapes arrive as ordinary files (the tape-only data they carry is ignored,
  as the retro-files format says).

### Known limits
- As in 1.7.0: TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported; a
  padded single-sided 80-track Research Machines disc (`rm-qd`) is the size of a padded double-sided 40-track one and
  opens read-only until its format is confirmed; copy-protected tracks are read but never written; DateStamper time
  stamps are kept but not shown; deleted Torch CP/N files can't be recovered yet; the builds are not signed.

### Building from source
The shared code is the DiskWranglerCore library (version 1.4.1), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `cpmdw` in each; and the
complete source (`...-source.tar.gz`, with `core/`).
