## CP/M Disk Wrangler 1.8.1

A clearer manual page for `cpmdw`. It moves to the DiskWranglerCore library version 1.6.0 (from 1.5.0). Nothing
changes in how the program reads or writes discs.

### Changed
- **The manual page (`man cpmdw`) is easier to read:** no stretched spaces between words, a comment above every
  example, and the links on lines of their own. It now says plainly that the format library built into `cpmdw`
  includes the disc definitions (the `diskdefs` file) of cpmtools 2.23, and that cpmtools itself is a separate
  package, not part of CP/M Disk Wrangler and not needed to run it.

### Known limits
- As in 1.8.0: while its second side is still empty, a raw double-sided `rm-sd` image is also an 80-track
  single-sided disc, so it opens read-only until its format is confirmed (an ImageDisk or DSK file of it opens
  writable); TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported; a
  padded single-sided 80-track Research Machines disc (`rm-qd`) is the size of a padded double-sided 40-track one and
  opens read-only until its format is confirmed; copy-protected tracks are read but never written; DateStamper time
  stamps are kept but not shown; deleted Torch CP/N files can't be recovered yet; the builds are not signed.

### Building from source
The shared code is the DiskWranglerCore library (version 1.6.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release. For 32-bit
Windows (Windows 7 SP1 and later), see `core/docs/building-windows-32bit.md`.

### Downloads
