## CP/M Disk Wrangler 1.5.0

The program now shares its code with Acorn Disk Wrangler, in the DiskWranglerCore library (version 1.1.0). Most of
that can't be seen from outside; what can is below.

### New
- **Command-line program `cpmdw`.** Installed beside the program (Windows: beside the `.exe`; macOS: inside the app,
  `Contents/MacOS/cpmdw`; Linux: `/usr/bin/cpmdw` from the `.deb`, or the AppImage started under the name `cpmdw`).
  It lists, extracts, adds, removes, renames and changes files, makes new discs and converts between kinds of image,
  with `--json`, exit codes and `--dry-run`. A disc whose format isn't confirmed (including one just made) needs
  `--format=NAME` to be changed. See "Command line" in the README.
- **Acorn discs open in Acorn Disk Wrangler.** Opening an ADFS, DFS, DOS Plus or PC disc starts Acorn Disk Wrangler
  with it, if it is installed, and says so. If it can't be found, the message has a **Locate...** button beside
  "Choose a format...": show the program once and it is remembered.
- **A question when a disc could be read two ways**, as in Acorn Disk Wrangler.

### Changed
- **Checked saving.** A save now checks the new file (every changed sector, and each side's directory read back from
  it) before it replaces the old one; the `.bak` copy is a hard link where the system allows. Raw images are read as
  needed rather than loaded whole.
- **Folders are read the same way everywhere.** Adding or dropping a folder, and `cpmdw put`, read it alike: folders
  first, then files, in name order ignoring case; linked files and folders inside a folder are skipped (a file or
  folder you name yourself is read as before). Files nested more than 8 folders deep are no longer left out, and Acorn
  `.inf` files inside a dropped folder are no longer copied onto the CP/M disc. A file that can't be read or is too
  large is reported and the rest are still added.
- **Torch CP/N names as Torch keeps them.** With *Allow lower-case file names* on, a file added to a Torch CP/N disc
  keeps its lower-case name, and such files (also ones already on a real Torch disc) can be replaced, renamed and
  deleted; `readme.txt` and `README.TXT` are two files, as on a CP/M disc. National letters can be used where the
  disc's character set allows. With lower-case names off, names are upper-cased as before.
- **`microbee40` is no longer offered.** cpmtools' `microbee40` (one side of 80 cylinders) describes no real Microbee
  disc; use `microbee-ds40` (40 cylinders on two sides) for a 5.25-inch DS40 disc, or `microbee-ss80` for a 3.5-inch
  SS80 disc. (A diskdefs file of your own can still define it.)

### Fixed
- **Dragging files out on Linux.** Files dragged out onto GNOME Files (Nautilus), a terminal or another program now
  arrive on Linux under X11 and on a GNOME Wayland session; before, GNOME Files (and, on Wayland, every other
  program) got nothing. "Copied N files out of the disc" now appears once the files have been asked for and written,
  and when a drag let go outside the program copied nothing (the drop was refused or cancelled, or no file was asked
  for) the status line says "No files were copied out of the disc".

### Known limits
- TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported.
- New Sharp `sds400` discs can't be made yet.
- Deleted Torch CP/N files can't be recovered.
- Acorn Z80 CP/M discs other than the first of the set tried (`cpm2`-`cpm7`) are found only by searching, and open
  read-only until their format is confirmed.
- None of the builds is signed: Windows and macOS warn the first time (see the README).

### Building from source
The shared code is the DiskWranglerCore library (version 1.1.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `cpmdw` in each; and the
complete source (`...-source.tar.gz`, with `core/`).
