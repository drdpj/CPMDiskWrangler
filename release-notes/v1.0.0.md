## CP/M Disk Wrangler 1.0.0

The first stable release. CP/M Disk Wrangler views and edits CP/M disc images - raw, ImageDisk, DSK (standard and
extended) and TeleDisk - and works out each disc's format from its contents, with about 140 formats built in,
including cpmtools' library, Amstrad, Kaypro, Osborne, Microbee, Research Machines, Sharp, Acorn's Z80 second
processor and Torch CP/N. Files can be added, extracted, renamed and deleted, user numbers, attributes and CP/M 3
labels set, new discs made in any format, and files exchanged with Acorn Disk Wrangler and other tools through the
open [retro-files](https://github.com/drdpj/CPMDiskWrangler/blob/main/docs/retro-files-format.md) format.

### Since 1.0.0 release candidate 7
- No changes to what the program does: 1.0.0 is release candidate 7 with a tidier README.
- For developers: the sources have moved into `src/` (the diskdefs into `src/resources/`), and AGENTS.md is split,
  with the format notes in `docs/disc-formats.md`, format detection in `docs/detection.md` and the tests in
  `docs/testing.md`.

### Known limits
- TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported.
- New Sharp `sds400` discs can't be made yet, and a raw `.RAW` of one isn't read; open the ImageDisk or DSK version.
- Deleted Torch CP/N files can't be recovered yet, and Torch CP/N discs written here haven't yet been checked on a
  real Torch.
- None of the builds is signed: Windows and macOS warn the first time (see the README).
