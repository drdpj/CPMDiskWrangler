## CP/M Disk Wrangler 1.5.1

A fix to how the format of Acorn Z80 CP/M discs is worked out. It uses the same DiskWranglerCore library as 1.5.0
(version 1.1.0).

### Fixed
- **Acorn Z80 discs saved side after side.** A raw Acorn Z80 CP/M image that holds all of side 0 and then all of
  side 1 (rather than the two sides cylinder by cylinder) now opens as an Acorn Z80 disc and can be changed. Before,
  it opened read-only in a layout the program had guessed, and every file reaching the second side read wrong.
  Saving keeps the file in the order it was in. This was the known limit in 1.5.0 about Acorn Z80 discs `cpm2` to
  `cpm7`: all six now open as Acorn Z80 discs, every file as an independent reader reads it.

### Known limits
- TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported.
- New Sharp `sds400` discs can't be made yet.
- Deleted Torch CP/N files can't be recovered.
- None of the builds is signed: Windows and macOS warn the first time (see the README).

### Building from source
The shared code is the DiskWranglerCore library (version 1.1.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `cpmdw` in each; and the
complete source (`...-source.tar.gz`, with `core/`).
