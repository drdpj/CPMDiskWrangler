## CP/M Disk Wrangler 1.6.0

Discs whose track 0 differs from the rest can now be kept as raw images. It uses the DiskWranglerCore library
version 1.2.0.

### New
- **Research Machines, Osborne 8-inch double-density and Vector Graphic discs as raw images.** These discs have a
  track 0 of their own shape (on Research Machines discs, single density with fewer sectors). New disc image and
  Save As can now make them as raw images, with track 0 kept at its own size, as real Research Machines images are
  kept; `cpmdw new` and `cpmdw convert` do the same. Before, raw was refused for them. Your Research Machines discs
  go raw to ImageDisk to raw, and raw to extended DSK to raw, byte for byte, and cpmtools reads the raw images clean.

### Known limits
- A raw image can't say that track 0 was single density: Save As ImageDisk from a raw image records it as double
  density (the data is the same). A double-sided disc that gives only side 0 its own track 0 needs ImageDisk or DSK.
- TeleDisk images can't be saved as TeleDisk, and TeleDisk 1.x "advanced compression" isn't supported.
- New Sharp `sds400` discs can't be made yet.
- Deleted Torch CP/N files can't be recovered.
- None of the builds is signed: Windows and macOS warn the first time (see the README).

### Building from source
The shared code is the DiskWranglerCore library (version 1.2.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `cpmdw` in each; and the
